# YOLOv5 小狗目标检测作业

## 1. 视频来源与类别
- 视频来源：B站（UP主：是可爱点点喔）快乐小狗奔跑视频。
- 类别名称：dog（仅 1 类目标）。

## 2. 数据规范
- 数据筛选：从视频中截取 83 帧图像，人工剔除了严重模糊和残缺的无效帧，并对清晰的帧进行了精标。
- 标注数量：共计包含 55 个有效标注框。
- 划分比例：按 80% 训练集 / 20% 验证集 进行划分。

## 3. 验证集指标与遇到问题
- 验证集指标：模型训练 50 轮后，mAP50 达到 93.9%，召回率（Recall）达到 100%。
- 遇到的问题：
  1. Windows 环境下多线程加载数据易导致死锁，通过添加 `--workers 0` 参数解决。
  2. 自动下载预训练权重和数据时受网络限制，通过国内镜像手动下载解决。
